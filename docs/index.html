ATMlib

Arduboy Tracker Music — a four-channel chiptune playroutine for the Arduboy, built on Davey Taylor’s Squawk synthesizer and the original TEAM a.r.g. score format by Joeri Gantois (JO3RI).

This page documents the current library in this project: compact command macros in atm_cmds.h, compile-time waveforms in atm_config.h, music via ATM.play(score), and one-shot effects via ATM.playSfx(track, ch).

4 channels

Default mix: pulse, square, saw, noise. Any channel can be compiled to pulse, square, saw, noise, or off.

Song + SFX

Background score keeps running while a raw SFX track steals one voice and returns it when the effect ends.

Tracker editor

Single-file HTML editor (v0.1.7): song arrangement, pattern notes, SFX mode, load/export song.h.

Cues

ATM_CUE(id) in a score; the sketch reads it with ATM.check() to sync animation or gameplay.

Quick start

#include <Arduboy2.h>
#include "ATMlib.h"
#include "song.h"
#include "sfx.h"

Arduboy2 arduboy;
ATMsynth ATM;

void setup() {
  arduboy.begin();
  arduboy.audio.on();
  ATM.play(score);
}

void loop() {
  if (!arduboy.nextFrame()) return;
  arduboy.pollButtons();
  if (arduboy.justPressed(A_BUTTON))
    ATM.playSfx(sfx0, CH_THREE);
}

What lives in the library

FileRole
ATMlib.h / ATMlib.cppPlayroutine, ISR mixer, ATMsynth class
atm_cmds.hNotes C2–D7 and all song / FX macros
atm_config.hPer-channel waveform and speaker wiring
song.hPacked score for ATM.play()
sfx.hOne-track effects for ATM.playSfx()

ATMlib is based on Squawk. Scores are a compact command stream, not a raw sample dump. Preview in the HTML tracker is Web Audio — it is not cycle-accurate to the AVR ISR. For a device-faithful listen, compile a hex and run it in Ardens or on hardware.

API

Instantiate one ATMsynth and call these from the sketch.

MethodWhat it does
play(const byte *song)Start a packed score from PROGMEM (header + tracks).
playPause()Toggle pause / resume.
pause() / resume()Explicit pause control.
stop()Halt playback.
muteChannel(ch) / unMuteChannel(ch)Silence or restore one of CH0–CH3.
playSfx(const byte *track, byte ch)Play a raw command stream on one channel. Music on the other channels continues.
check()Last ATM_CUE byte (0 if none since last read).
check(uint8_t id)1 if the last cue equals id (does not clear).

Channels

#define CH_ZERO   0
#define CH_ONE    1
#define CH_TWO    2
#define CH_THREE  3

Defaults at compile time: CH0 pulse, CH1 square, CH2 saw, CH3 noise. Change them in atm_config.h and rebuild.

SFX helper

A one-track effect is a PROGMEM byte list that ends with ATM_STOP_CHAN. The header provides a wrapper:

ATM_SFX_TRACK(sfxJump,
  ATM_VOL(48),
  ATM_NOTE_C5,
  ATM_DELAY(8)
);
// expands to: const uint8_t sfxJump[] PROGMEM = { …, ATM_STOP_CHAN };

Call ATM.playSfx(sfxJump, CH_THREE); — typical pattern: keep noise or a spare voice for hits so the melody is not stolen.

Cues from the score

uint8_t id = ATM.check();
if (ATM.check(3)) {
  // last cue was 3 — e.g. fire a sprite frame
}

Commands

Macros from atm_cmds.h. Notes occupy values 1–63 (C2 through D7). Zero is rest / mute. Sharps use a trailing underscore: ATM_NOTE_A5_.

Flow

MacroMeaning
ATM_STOPStop this track.
ATM_STOP_CHANStop this channel (SFX end marker).
ATM_DELAY(n)Wait n ticks (short form).
ATM_LONG_DELAY(n)Wait with an extra byte of length.
ATM_GOTO(track)Jump to another track once.
ATM_REPEAT(times, track)Call a track a number of times.
ATM_RETURNReturn from a call.
ATM_GOTO_ADV(ch0,ch1,ch2,ch3)Point all four channels at new tracks.
ATM_SET_TEMPO(n) / ATM_ADD_TEMPO(n)Tick rate.
ATM_CUE(value)Store a byte for ATM.check().

Volume & pitch FX

MacroMeaning
ATM_VOL(v)Set volume (typical 0–63).
ATM_SL_VOL(d) / ATM_SL_VOL_ADV(d, ticks) / ATM_SL_VOL_OFFVolume slide.
ATM_SL_FRQ(d) / ATM_SL_FRQ_ADV(d, ticks) / ATM_SL_FRQ_OFFFrequency slide.
ATM_ARP(third, ticks) / ATM_ARP_OFFArpeggio.
ATM_NOISE(cfg) / ATM_NOISE_OFFRetrigger noise on CH3.
ATM_ADD_TRA(n) / ATM_SET_TRA(n) / ATM_TRA_OFFTranspose.
ATM_TREM(depth, rate) / ATM_TREM_OFFTremolo.
ATM_VIB(depth, rate) / ATM_VIB_OFFVibrato.
ATM_GLIS(noteTicks) / ATM_GLIS_OFFGlissando.
ATM_CUT(amount) / ATM_CUT_OFFNote cut.
ATM_WAVEFORM(type)0 pulse, 1 square, 2 noise (runtime where supported).

Example score fragment

Song menuSong[] = {
  ATM_VOL(48),
  ATM_NOTE_C5,
  ATM_DELAY(16),
  ATM_REPEAT(7, 2),
  ATM_GOTO_ADV(7, 19, 0, 23),
  ATM_RETURN,
};

ATM Tracker Editor

Single-file HTML tracker for this library. Open atm-tracker-editor.html in a browser. Current release: 0.1.7 — zip as ATMtracker-vMAJOR.MINOR.PATCH.zip.

Modes

You always start in SONG. Switch with the header buttons.

SONG

Four channel lanes. Patterns appear as blocks (width = tick length). Unique patterns have unique colors; copies of the same pattern share a color.

  • Left list: all patterns. Drag one onto a lane to append it.
  • Blocks pack left. No gaps. Delete a block (×) and the rest slide left.
  • Click a block (or a list item) to enter PATTERN mode for that clip.

PATTERN

One lane only. This is where you write notes.

  • Record: notes are written and the cursor advances. Hold a key to grow tick length.
  • Edit: notes are written / heard but the cursor stays. Move it with Left / Right.
  • Drag a note to move it (length comes along). If the landing gap is shorter, the note is clipped.
  • Drag the right edge of a note to change length.

SOUNDFX

One pattern, one voice. No arrangement blocks. Choose Play as CH0–3 in the header (pulse / square / tone / noise). Export is ATM_SFX_TRACK for ATM.playSfx(sfxTrack, ch).

Switching SONG and SFX asks for confirmation and starts from scratch.

Load

Load accepts JSON and song.h written with ATM commands. Macros such as ATM_NOTE_A5_, ATM_SET_TRA(-5), ATM_SL_VOL(-4), ATM_STOP are expanded. Multiple arrays in one file: the first valid score header is imported as four channel patterns on the song timeline.

Very nested GOTO / REPEAT songs are flattened onto a 64-tick grid per channel so you can edit them.

Export

Pick commands or hex in the export panel.

  • SONG: const uint8_t score[] PROGMEM for ATM.play(score)
  • SFX: ATM_SFX_TRACK for ATM.playSfx

Rests and holds become ATM_DELAY. Arrangement becomes ATM_GOTO chains of pattern tracks.

Playback

Preview is Web Audio, not cycle-accurate Squawk. ArdensPlayer is a full AVR emulator and only matches the device when you run a compiled hex.

Keyboard

  • Space: Play / stop
  • Left / Right: Cursor in Pattern / Edit
  • Up / Down: Piano octave
  • Del: Clear selected note
  • A–L + sharps / Z–M and Q–U: piano

Web MIDI is supported. A computer-keyboard piano sits under the grid.

Config

Waveforms are fixed at compile time. Edit atm_config.h, then rebuild the sketch.

// ATM_WAVE_PULSE  0
// ATM_WAVE_SQUARE 1
// ATM_WAVE_NOISE  2   (use on channel 3; ATM_NOISE() is a song macro)
// ATM_WAVE_SAW    3
// ATM_WAVE_OFF    255  (no mixer for this channel — smaller ISR)

#define ATM_WAVE_CH0 ATM_WAVE_PULSE
#define ATM_WAVE_CH1 ATM_WAVE_SQUARE
#define ATM_WAVE_CH2 ATM_WAVE_SAW
#define ATM_WAVE_CH3 ATM_WAVE_NOISE

// Example: drop ch2 from the mixer
// #define ATM_WAVE_CH2 ATM_WAVE_OFF

// 0 = stock Arduboy speaker on OCR4A only
// 1 = also drive OCR4D (homemade / dual-pin wiring)
#define ATM_ALT_WIRING 0

Turning a channel ATM_WAVE_OFF removes it from the mixer ISR and saves cycles. Noise needs the LFSR path; keep it on CH3 unless you know you want noise elsewhere.
